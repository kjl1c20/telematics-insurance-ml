# Background
Usage-based insurance is quite an innovative solution where the cost of automobile insurance is based on the use of automobile. It makes use of data from telematics box to assess how you drive and how far you drive. Provided with this data, we can allow insurers to align driving behaviour with insurance premium rates through usage-based insurance. allowing insurers to more closely align driving behaviors with insurance premium rates through UBI. Many of the research suggested telematics can provide improved claims predictions, risk classification, and premium assessments.

This is my first official machine learning project from scratch. I am going to explore how we can make use of telematics and demographic data to help insurer decide the price of the insurance for each driver. This work is produced using synthetic data from the paper: "Synthetic Dataset Generation of Driver Telematics".
